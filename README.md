# Guia-rapido-de-MARKDOWN
Guia de estudo da linguagem Markdown prático para documentação no GitHub

Este repositório reúne meus estudos sobre a linguagem **Markdown**, utilizada para criar documentações e arquivos README no GitHub.

## 📚 Conteúdo

- Títulos
- Texto em negrito e itálico
- Listas
- Links
- Imagens
- Tabelas
- Blocos de código
- Citações
- Checklists
- Emojis

## 🎯 Objetivo

Aprender a documentar projetos de forma organizada e profissional para utilizá-los no meu portfólio de QA.
