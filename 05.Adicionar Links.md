# Capítulo 5 - Adicionar Links

- Utilize links para facilitar a navegação.
- O texto entre colchetes (`[]`) será exibido ao usuário.
- O endereço do link fica entre parênteses (`()`).
- É possível criar links para sites ou para outros arquivos do repositório.
---

## Link para um site

### Sintaxe

```markdown
[Google](https://www.google.com)
```

### Resultado

[Google](https://www.google.com)

---

## Link para outro arquivo do repositório

### Sintaxe

```markdown
[Capítulo 1 - Títulos](01-Titulos.md)
```

### Resultado

Quando publicado no GitHub, o link abrirá o arquivo **01-Titulos.md**.

---

## Como usar

```markdown
[Texto do link](URL)
```
