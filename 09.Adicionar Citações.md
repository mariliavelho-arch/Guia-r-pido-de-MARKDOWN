#  Capítulo 9 - Citações

## O que são?

As citações são utilizadas para destacar informações importantes, observações, avisos ou trechos de texto.

- Utilize citações para destacar informações.
- O símbolo `>` cria uma citação.
- As citações facilitam a leitura e chamam a atenção para conteúdos importantes.
---

## Sintaxe

```markdown
> Esta é uma citação.
```

---

## Resultado

> Esta é uma citação.

---

## Como usar

- Utilize o símbolo `>` antes do texto.
- Cada linha da citação deve começar com `>`.

---

## Citação com várias linhas

### Sintaxe

```markdown
> Primeira linha.
>
> Segunda linha.
```

### Resultado

> Primeira linha.
>
> Segunda linha.
