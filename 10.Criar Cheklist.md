# Capítulo 10 - Checklist

## O que é?

O checklist é utilizado para criar listas de tarefas, permitindo marcar itens concluídos e acompanhar o progresso.

- Utilize checklists para organizar tarefas.
- Marque as atividades concluídas com `x`.
- Deixe um espaço em branco para as tarefas pendentes

---

## Item não concluído

### Sintaxe

```markdown
- [ ] Estudar Markdown
```

### Resultado

- [ ] Estudar Markdown

---

## Item concluído

### Sintaxe

```markdown
- [x] Estudar Markdown
```

### Resultado

- [x] Estudar Markdown

---

## Exemplo

### Sintaxe

```markdown
## Lista de Estudos

- [x] Títulos
- [x] Formatação de Texto
- [ ] Links
- [ ] Tabelas
```

### Resultado

## Lista de Estudos

- [x] Títulos
- [x] Formatação de Texto
- [ ] Links
- [ ] Tabelas

---

## Como usar

- `- [ ]` → Tarefa não concluída.
- `- [x]` → Tarefa concluída.
