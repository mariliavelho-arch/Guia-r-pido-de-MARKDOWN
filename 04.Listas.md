# Capítulo 4 - Listas

- Utilize listas para organizar informações.
- Use listas não ordenadas quando a ordem não for importante.
- Use listas ordenadas quando houver uma sequência.
- Utilize subitens para agrupar informações relacionadas.
---

## Lista não ordenada

### Sintaxe

```markdown
- Item 1
- Item 2
- Item 3
```

### Resultado

- Item 1
- Item 2
- Item 3

---

## Lista ordenada

### Sintaxe

```markdown
1. Primeiro item
2. Segundo item
3. Terceiro item
```

### Resultado

1. Primeiro item
2. Segundo item
3. Terceiro item

---

## Lista aninhada (subitens)

### Sintaxe

```markdown
- Frutas
  - Maçã
  - Banana

- Bebidas
  - Água
  - Café
```

### Resultado

- Frutas
  - Maçã
  - Banana

- Bebidas
  - Água
  - Café

---

## Como usar

- `-` → Lista não ordenada.
- `1.` → Lista ordenada.
- Dois espaços antes do item → Subitem.
