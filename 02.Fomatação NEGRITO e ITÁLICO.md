# Capítulo 2 - Formatação de TEXTO

- Utilize **negrito** para destacar informações importantes.
- Utilize *itálico* para dar ênfase a palavras ou expressões.
- É possível combinar os dois estilos usando três asteriscos (`***`).

## Sintaxe

```markdown
**Negrito**

*Itálico*

***Negrito e Itálico***
```

## Como usar

- `**texto**` → **Negrito**
- `*texto*` → *Itálico*
- `***texto***` → ***Negrito e Itálico***
