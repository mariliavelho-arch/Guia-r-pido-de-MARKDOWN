#  Capítulo 1 - Títulos
- Utilize títulos para organizar o conteúdo.
- Quanto mais `#`, menor o nível do título.
- O Markdown permite até **6 níveis de títulos**.

## Sintaxe

```markdown
# Título 1
## Título 2
### Título 3
#### Título 4
##### Título 5
###### Título 6
```

## Como usar

- `#` → Título principal.
- `##` → Seções.
- `###` → Subseções.
- `####` até `######` → Divisões menores.
