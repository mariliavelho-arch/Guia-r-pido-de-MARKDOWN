#  Capítulo 11 - Emojis

## O que são?

Os emojis são utilizados para deixar documentos mais visuais, destacar informações e facilitar a leitura.
---

## Sintaxe

```markdown
🚀 Projeto iniciado

✅ Tarefa concluída

❌ Tarefa não concluída
```

---

## Resultado

🚀 Projeto iniciado

✅ Tarefa concluída

❌ Tarefa não concluída

---

## Exemplos

| Emoji | Significado |
|-------|-------------|
| 📖 | Documentação |
| 📝 | Anotações |
| 💻 | Código |
| 📋 | Lista |
| ☑️ | Checklist |
| 🔗 | Link |
| 🖼️ | Imagem |
| 📊 | Tabela |
| 💬 | Citação |
| ⚠️ | Atenção |
| ℹ️ | Informação |
| 🚀 | Projeto |
| 🐛 | Bug |
| 🔍 | Teste |
| ✅ | Concluído |
| ❌ | Erro |
| 📌 | Importante |

---

## Como usar

- Os emojis podem ser inseridos diretamente no texto.
- Utilize apenas quando fizerem sentido para destacar informações.
- Evite o uso excessivo para manter a documentação organizada.
